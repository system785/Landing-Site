# Landing Site — продающий лендинг для услуги «Создание сайтов для бизнеса»

Продающая одностраничная модель + блог статей для SEO. Адрес сайта:
**https://system785.github.io/Landing-Site/**

Репозиторий: **https://github.com/system785/Landing-Site**

## Что внутри

| Файл / папка | Назначение |
|---|---|
| `index.html` | Главная страница-лендинг: первый экран, боли, цены, кейсы, процесс, FAQ, контакты, форма заявки |
| `articles.html` | Страница статей (SEO-раздел) |
| `articles/` | Три статьи, включая материал на 1500+ слов о ценах на сайты |
| `privacy.html` | Политика конфиденциальности (ссылка в футере) |
| `css/style.css` | Дизайн-система: тёмный герой, светлые секции, адаптив от 320px |
| `js/main.js` | Скролл-анимации, меню, аккордеон, модальная форма, валидация |
| `img/` | Портрет, обложки кейсов и статей, фавикон (векторные) |
| `files/forma-zayavki.docx` | Форма заявки для скачивания (кнопка «Скачать форму заявки») |
| `robots.txt`, `sitemap.xml` | Индексация и карта сайта для Яндекса и Google |

## SEO

- Корректная иерархия заголовков: один `H1` на страницу, `H2`/`H3` по секциям;
- мета-теги `title`, `description`, `keywords`, `canonical`, Open Graph, Twitter Card;
- микроразметка JSON-LD: `WebSite`, `ProfessionalService`, `FAQPage`, `Article`, `BreadcrumbList`, `CollectionPage`;
- семантическая разметка (`header`, `main`, `section`, `article`, `aside`, `footer`), alt у изображений;
- `robots.txt` и `sitemap.xml` со ссылкой на адрес сайта и репозиторий.

```bash
# затем открыть http://127.0.0.1:8000/
```

## Публикация

Сайт опубликован через GitHub Pages (вкладка **Settings → Pages**, ветка `main`,
папка `/`). После изменений достаточно выполнить `git push` — публикация обновится автоматически.

## Яндекс.Метрика

В `<head>` страницы `index.html` лежит готовый, но закомментированный код счётчика.
Замените `XXXXXXXX` на номер вашего счётчика и раскомментируйте блок.
